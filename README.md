# Лендинг Goulash.tech

Неофициальный концепт для тестового задания. Данные в примерах условные. Страница не принимает заявки и не является каналом Goulash.

## Как открыть

Откройте `index.html` двойным кликом. Сборка, локальный сервер и интернет для просмотра не нужны. Шрифт и стили лежат рядом с файлом.

## Файлы

- `index.html` — тексты, структура и примеры интерфейса
- `styles.css` — оформление
- `app.js` — вкладки, мобильное меню и демонстрационная форма
- `assets/fonts/Onest-Variable.ttf` — шрифт Onest
- `assets/fonts/OFL.txt` — лицензия SIL Open Font License

Официальный знак не входил в материалы проекта, поэтому в шапке только надпись «Goulash.tech».

## Onest

Переменный TTF скачан из официального репозитория Google Fonts:

https://github.com/google/fonts/tree/main/ofl/onest

Файл: `ofl/onest/Onest[wght].ttf`, сохранён как `assets/fonts/Onest-Variable.ttf`. Подключение локальное, через `@font-face` в `styles.css`. Внешний CSS Google Fonts не используется.

## Где менять тексты и данные

Все видимые тексты и цифры примеров — в `index.html`. Повторяющиеся заказы согласованы между экранами:

- №2841: готовность 19:45, выезд 19:48, прогноз 20:08, обещано 20:10
- №2843: готовность 19:49, выезд 19:52, прогноз 20:22, обещано 20:15

Время сценария фиксировано: пятница, 19:42.

## Вкладки

Четыре независимые группы по две вкладки: заказы, кухня, рейс, показатели филиалов. Переключение меняет содержимое только своей группы. С клавиатуры: стрелки влево и вправо, Home и End. Первое состояние каждого экрана видно и без клика.

## Форма

- Имя: от 2 до 60 символов, только буквы, пробел, дефис или апостроф.
- Телефон: маска `+7 (XXX) XXX-XX-XX`. Первая 8 заменяется на +7, вставка номера в любом формате приводится к маске. Код после +7 должен начинаться с 3, 4, 8 или 9.
- Название компании: от 2 до 100 символов, должно содержать хотя бы одну букву или цифру.
- Город: от 2 до 60 символов, только буквы, пробел, точка, дефис или апостроф.
- Количество точек: обязательный выбор.

Ошибки показываются у полей после ухода с поля и при отправке. При успехе карточка с формой скрывается, заголовок блока меняется на «Заявка отправлена», под ним появляется благодарность. Если сети нет или сервер ответил ошибкой, появляется «Не удалось отправить заявку», введённые данные сохраняются, кнопка меняется на «Повторить отправку».

Адрес приёма заявок задаётся в `LEAD_ENDPOINT` в `app.js`: данные уходят туда POST-запросом в JSON (`name`, `phone` в виде `+7XXXXXXXXXX`, `company`, `city`, `locations`). Пока адрес пустой, отправка только имитируется и данные не покидают браузер. Для реального приёма нужен backend с серверной валидацией.

Пока JavaScript не загрузился, кнопка отправки выключена, чтобы контакты не попали в адрес страницы.

## Что использовано

HTML, CSS и JavaScript без сборки и внешних библиотек. Шрифт получен по сети только при создании проекта. Единственный внешний скрипт — счётчик Яндекс Метрики (id 113011854) в `<head>` `index.html`.

## Что проверено

- Синтаксис `app.js`
- Локальная загрузка Onest
- Вкладки переключают своё содержимое и не задевают соседние группы
- Валидация формы, загрузка, смоделированная ошибка и успешный повтор
- Вёрстка на широком экране и на ширине 390 и 320 px: горизонтальной прокрутки страницы нет
- Чистый `#00FFFF` не используется как заливка

Проверка в браузере шла через временный локальный просмотр, потому что инструмент браузера не открывает `file://`. Сама страница рассчитана на открытие файла напрямую.

Для сдачи исходного тестового задания понадобятся публикация страницы по ссылке и отдельный промо-креатив.
